## Abstract

The Multi Level Parking System is a proposed Java application designed to improve parking management in locations with limited space and increasing vehicle traffic. It organizes parking across multiple levels and aims to monitor slot availability, allocate suitable spaces, and maintain vehicle entry and exit records. A centralized administrative interface is planned to support occupancy monitoring, parking slot management, vehicle tracking, and parking information reporting. Users will be able to identify available spaces more conveniently, reducing the time spent searching for parking. By coordinating slot allocation and maintaining organized records, the project aims to reduce congestion and improve the use of available parking capacity. The proposed solution is suitable for shopping malls, hospitals, educational institutions, residential complexes, and other busy facilities that require structured parking management.
